# Client OpenAI. La borne 1.66 garantit la présence de la Responses API
# (client.responses.create) utilisée exclusivement par ce projet.

# Choisi contre pdf2image, qui exige le binaire système poppler.

# anciennes) ; utils/api.py et ocr.py gèrent les deux cas.
pymupdf>=1.24.0

# Génération du document final. Aucune IA à cette étape.
python-docx>=1.1.0
